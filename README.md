# 훈뮤직툴 v1.9.3 클립 정밀 편집기

PC·모바일에서 사용하는 개인용 음악 작업 웹앱입니다.

## v1.9.3 핵심 변경

- 기존 트랙을 재생선 위치에서 여러 클립으로 분할
- 분할 클립을 독립적으로 이동·앞뒤 자르기·삭제
- 클립 삭제 후 실행 취소로 즉시 복구
- 클립별 음량·페이드인·페이드아웃 설정
- 반복 시작·끝 지점 설정 및 구간 반복 재생
- 재생 위치 표시와 확대 화면 자동 스크롤
- 기존 v1.9.2 트랙을 기본 클립으로 자동 변환
- 앱 미리 듣기와 WAV 내보내기에 같은 클립 계산 적용
- 모바일 클립 이동 감도와 자르기 손잡이 터치 영역 개선

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 브라우저가 열리지 않으면 폴더 안의 `index.html`을 Chrome 또는 Edge에서 여세요. 마이크와 PWA 기능은 로컬 서버 또는 HTTPS 배포 환경에서 가장 안정적입니다.

## 배포

GitHub Pages나 Netlify에는 배포용 폴더의 파일과 폴더를 그대로 업로드합니다. 이전 버전 위에 덮어쓴 뒤 앱을 완전히 종료하고 다시 열어 서비스 워커 캐시를 갱신하세요.

## 클립 편집 방법

1. 믹서 탭에서 보컬과 MR이 분리된 녹음을 선택합니다.
2. 타임라인의 클립을 선택하고 재생선을 원하는 위치로 옮깁니다.
3. `분할` 버튼 또는 `S` 키로 클립을 두 구간으로 나눕니다.
4. 각 클립을 독립적으로 이동하거나 양끝 손잡이로 자릅니다.
5. 선택 클립 설정에서 위치·원본 구간·음량·페이드를 정밀 조절합니다.
6. 반복 시작·끝을 지정해 특정 소절을 반복해서 확인합니다.
7. 전체 재생으로 확인한 뒤 WAV 믹스를 만듭니다.

모든 분할과 삭제는 원본 오디오 파일을 보존하는 비파괴 편집 방식입니다.
