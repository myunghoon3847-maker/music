# 훈뮤직툴 v1.9.4 트랙 추가·구간 녹음

PC·모바일에서 사용하는 개인용 음악 작업 웹앱입니다.

## v1.9.4 핵심 변경

- `트랙 추가`와 `선택 트랙 녹음`을 서로 다른 동작으로 분리
- 녹음하지 않은 빈 트랙을 먼저 생성하고 타임라인에 표시
- 추가 트랙 카드에서 녹음 대상을 명확하게 선택
- 현재 재생선 위치를 녹음 시작점으로 사용
- 시작 시간을 초 단위로 직접 입력해 원하는 구간부터 녹음
- 3초 카운트인 후 선택한 위치에서 기존 믹스를 재생하며 녹음
- 기존 녹음이 있는 추가 트랙은 확인 후 다시 녹음 가능
- 새 녹음을 선택 트랙의 지정 위치에 자동 배치
- 녹음 후 기존 클립 분할·이동·자르기·WAV 내보내기 기능과 연결

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 브라우저가 열리지 않으면 폴더 안의 `index.html`을 Chrome 또는 Edge에서 여세요. 마이크와 PWA 기능은 로컬 서버 또는 HTTPS 배포 환경에서 가장 안정적입니다.

## 배포

GitHub Pages나 Netlify에는 배포용 폴더의 파일과 폴더를 그대로 업로드합니다. 이전 버전 위에 덮어쓴 뒤 앱을 완전히 종료하고 다시 열어 서비스 워커 캐시를 갱신하세요.

## 추가 트랙 녹음 방법

1. 믹서에서 보컬과 MR이 분리된 녹음을 선택합니다.
2. `새 트랙 이름`을 입력하고 `트랙 추가`를 누릅니다.
3. 추가된 트랙 카드의 `녹음 대상`을 누르거나 카드를 선택합니다.
4. 타임라인 빈 곳을 눌러 재생선을 옮긴 뒤 `현재 재생선 사용`을 누릅니다.
5. 필요하면 녹음 시작 위치를 초 단위로 직접 수정합니다.
6. `선택 트랙 녹음`을 누르고 카운트인 후 녹음합니다.
7. 정지하면 녹음이 선택 트랙의 지정 위치에 저장됩니다.
8. 파형을 이동·분할·자른 뒤 WAV 믹스를 만들 수 있습니다.

추가 트랙을 녹음할 때는 기존 믹스가 마이크에 다시 들어가지 않도록 유선 이어폰 사용을 권장합니다.
