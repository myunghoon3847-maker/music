# 훈뮤직툴 v1.8.1 안정화판

이번 버전은 v1.8의 PC 작업실 UI를 기반으로, 앞으로 믹싱·트랙 편집 기능을 추가하기 위한 공통 제어와 프로젝트 관리 기반을 정리했습니다.

## 핵심 변경 사항

- PC 하단 공통 재생 제어 바
- Space 재생·일시정지, R 녹음, Esc 전체 정지 단축키
- 현재 재생 중인 기능과 상태 표시
- 왼쪽 사이드바 접기·펼치기 및 상태 저장
- 녹음 프로젝트 생성·선택·수정·삭제
- 녹음을 프로젝트별로 자동 분류
- 기존 녹음은 기본 프로젝트로 자동 이전
- 프로젝트 삭제 시 녹음은 기본 프로젝트로 안전하게 이동
- 프로젝트 단위 녹음 목록과 전체 삭제
- 새 기능을 `core/projects.js`, `core/transport.js`로 분리

## PC 단축키

- `Space`: 현재 화면의 재생 또는 일시정지
- `R`: 녹음 탭으로 이동해 녹음 시작·정지
- `Esc`: 모든 오디오와 분석 기능 정지

입력칸, 메모칸, 선택 메뉴를 사용하는 중에는 단축키가 작동하지 않습니다.

## 프로젝트 사용

녹음 탭 상단에서 프로젝트를 선택합니다. 새로 녹음한 보컬·MR 트랙과 믹스 파일은 선택한 프로젝트에 저장됩니다. 기존 버전의 녹음은 `기본 녹음 프로젝트`에 자동으로 정리됩니다.

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 모바일에서는 HTTPS로 배포한 주소를 열어 홈 화면에 설치합니다.
