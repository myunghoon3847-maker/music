# 훈뮤직툴 v1.1

메트로놈, 실시간 음정 튜너, 코드 진행 생성기를 포함한 모바일 우선 개인용 음악 연습 PWA입니다.

## 포함 기능

### 메트로놈
- BPM 30~240
- 2/4, 3/4, 4/4, 6/8 박자
- 첫 박자 강조, 볼륨 조절, TAP 템포

### 음정 튜너
- 마이크 기반 실시간 음정 감지
- 음 이름, 옥타브, 주파수, cents 오차 표시
- 낮음·정확·높음 상태 및 바늘형 미터
- 크로매틱 튜너
- 기타 표준 튜닝 E A D G B E
- 기타 Drop D 튜닝
- A4 기준 주파수 430~450Hz 조절
- 마이크 입력은 기기 내부에서만 분석하며 저장하거나 전송하지 않음

### 코드 생성기
- 조성과 분위기에 따른 4마디 코드 진행 생성
- 코드 구성음 표시, 진행 복사, Web Audio 코드 재생

### 공통
- 모바일 반응형 UI
- 최근 BPM·조성·분위기·튜닝 설정 저장
- 오프라인 캐시 및 PWA 설치

## 실행 방법

### 메트로놈과 코드 생성기만 확인
`index.html`을 브라우저에서 열어 사용할 수 있습니다.

### 음정 튜너까지 사용
브라우저 보안 정책상 마이크는 HTTPS 또는 localhost 환경이 필요합니다.

Python이 설치되어 있다면 이 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 8080
```

그다음 Chrome 또는 Edge에서 `http://localhost:8080`을 열고 튜너의 마이크 권한을 허용합니다.

스마트폰에서는 GitHub Pages, Netlify, Cloudflare Pages 등에 배포한 HTTPS 주소로 접속해야 합니다.

## 튜너 사용 팁

- 주변 소음이 적은 곳에서 사용합니다.
- 악기와 스마트폰 마이크를 너무 가까이 붙이지 않습니다.
- 한 음을 짧게 튕기기보다 1~2초 길게 유지합니다.
- 기타 프리셋에서는 한 줄씩 따로 연주합니다.
