# 훈뮤직툴 v1.6.5 보컬튠·녹음 분리판

보컬 음정 연습과 MR 녹음실을 서로 다른 탭으로 분리하고, 저장된 녹음의 제목과 메모를 관리할 수 있게 만든 버전입니다.

## 핵심 변경

- `보컬튠`과 `녹음`을 완전히 별도 탭으로 분리
- 녹음 탭에 MR 선택, 싱크 보정, 녹음, 내 녹음을 한곳에 배치
- 녹음 전 제목과 메모 입력 가능
- 저장된 녹음의 제목 수정 가능
- 저장된 녹음에 최대 500자 메모 작성·수정 가능
- 기존 녹음에도 제목·메모 수정 기능 적용
- 제목·메모는 녹음 파일과 함께 브라우저 기기 저장소에 보관
- 기존 MR 합성 녹음, 싱크 보정, 전용 플레이어 유지

## 사용

1. 상단 `녹음` 탭을 엽니다.
2. MR을 선택하고 싱크 값을 확인합니다.
3. 녹음 제목과 필요한 메모를 입력합니다.
4. 녹음 후 `내 녹음`에서 `수정`을 눌러 제목과 메모를 다시 편집합니다.
