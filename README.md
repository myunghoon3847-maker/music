# 훈뮤직툴 v1.9.1 WAV 믹스·추가 트랙 녹음

보컬과 MR을 앱 안에서 믹싱하고, 설정한 결과를 WAV 파일로 만들며, 믹서에서 새 녹음 트랙을 추가할 수 있는 버전입니다.

## 핵심 변경 사항

- 현재 믹서 설정을 44.1kHz·스테레오·16bit WAV로 생성
- WAV 결과를 앱 안에서 먼저 재생한 뒤 파일로 저장
- 트랙 음량·팬·위치·페이드·음소거·솔로·마스터 음량 반영
- 오프라인 오디오 렌더링으로 재생 끊김 없이 결과 생성
- 출력 피크 검사와 클리핑 위험 안내
- 원본 믹스와 현재 믹스 비교 재생
- 트랙별 초기화와 숫자 직접 입력
- 믹서 설정 변경됨·저장 중·저장됨 상태 표시
- 믹서 안에서 빈 트랙을 추가하고 마이크로 녹음
- 추가 녹음 트랙의 재생·음량·팬·위치·페이드·삭제
- 추가 트랙도 WAV 믹스 결과에 포함

## 추가 트랙 녹음

1. 믹서에서 보컬·MR 녹음을 선택합니다.
2. 이어폰을 연결합니다.
3. `빈 트랙 추가 녹음`에서 트랙 이름을 입력합니다.
4. `＋ 빈 트랙 녹음`을 누르면 카운트인 뒤 현재 믹스가 재생되며 녹음됩니다.
5. `정지·트랙 저장`을 누르면 현재 프로젝트 녹음에 새 트랙으로 보관됩니다.

추가 녹음은 브라우저 마이크 입력 특성상 기기별로 몇 ms 차이가 날 수 있습니다. 저장 후 트랙 위치를 ±10ms 단위로 조절할 수 있습니다.

## WAV 내보내기

1. 트랙 음량과 싱크를 맞춥니다.
2. 파일명을 입력하고 `WAV 믹스 만들기`를 누릅니다.
3. 결과를 앱 안에서 확인합니다.
4. `WAV 파일 저장`을 누릅니다.

WAV 결과는 임시로만 유지되며 앱을 새로 열면 정리됩니다. 보컬·MR·추가 트랙 원본은 변경되지 않습니다.

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 모바일에서는 HTTPS 배포 주소로 열어 홈 화면에 설치합니다.
