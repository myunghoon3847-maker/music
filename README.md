# 훈뮤직툴 v1.7 보컬·MR 2트랙 기반판

이번 버전은 후속 믹싱·음정/리듬 수정·마스터링 기능의 기반이 되는 **보컬과 MR 분리 트랙 저장 구조**를 추가한 버전입니다.

## 핵심 변경

- 새 녹음부터 보컬 마이크 원본을 별도 트랙으로 저장
- 선택한 MR 원본을 별도 트랙으로 저장
- 기존처럼 바로 들을 수 있는 간편 재생(믹스) 파일도 함께 생성
- 저장된 녹음에 `2트랙` 표시
- `분리 트랙`을 열어 보컬 트랙과 MR 트랙을 각각 파일로 저장 가능
- 싱크 보정값에 따라 타임라인 배치 방법 표시
- 녹음 제목·메모 수정 기능 유지
- 기존 MR 싱크 보정, 카운트인, 일시정지·재개, 전용 플레이어 유지

## 사용

1. `녹음` 탭에서 MR 파일을 선택합니다.
2. 싱크 보정값과 제목·메모를 설정합니다.
3. 녹음을 시작하고 정지·저장합니다.
4. `내 녹음`에서 `분리 트랙 2개`를 펼칩니다.
5. 보컬과 MR을 각각 `트랙 저장`할 수 있습니다.

## 알아둘 점

- 기존 v1.6.5 이전 녹음은 이미 한 파일로 합쳐졌기 때문에 자동 분리되지 않습니다.
- MR 원본도 녹음 프로젝트와 함께 브라우저 저장소에 보관되므로 이전 버전보다 저장 공간을 더 사용합니다.
- 이번 버전은 분리 트랙 저장 기반까지 구현했습니다. 실제 툰·믹싱·마스터링 편집기는 다음 단계에서 추가합니다.
