# 훈뮤직툴 v1.5

코드 진행 생성기, 메트로놈, 악기 튜너, 보컬 음정 연습에 **프로그램 내부 보컬 녹음 기능**을 추가한 개인용 음악 제작·연습 프로그램입니다.

## 가장 쉬운 실행 방법

1. 압축을 풉니다.
2. 폴더 안의 **`훈뮤직툴 실행.bat`**을 더블클릭합니다.
3. 약 2초 후 Chrome 또는 Edge에서 훈뮤직툴이 자동으로 열립니다.
4. 상단의 **보컬튠** 탭을 누릅니다.
5. 녹음 이름을 입력하고 **녹음 시작**을 누른 뒤 마이크 권한을 허용합니다.
6. 녹음이 끝나면 **정지·저장**을 누릅니다.
7. 저장된 녹음은 보컬튠 화면의 **내 녹음**에서 재생하거나 파일로 저장할 수 있습니다.

> 보컬튠, 튜너, 녹음 기능은 마이크 보안 정책 때문에 `index.html`을 직접 여는 방식이 아니라 실행 배치 파일 또는 HTTPS 주소로 열어야 합니다.

## v1.5 보컬 녹음

- 보컬튠 화면 안에서 마이크 녹음 시작
- 실시간 녹음 시간 표시
- 마이크 입력 레벨 표시
- 녹음 일시정지·계속 녹음
- 정지와 동시에 브라우저 내부 저장소에 자동 저장
- 프로그램 안에서 녹음 재생
- 개별 녹음 파일 저장
- 개별 삭제 및 전체 삭제
- 녹음 이름 지정
- 녹음 날짜, 길이, 파일 크기 표시
- 새로고침하거나 프로그램을 다시 열어도 녹음 목록 유지
- 최대 30분 자동 녹음 제한

녹음 파일은 브라우저의 **IndexedDB 기기 저장 공간**에만 저장되며 외부 서버로 전송하지 않습니다. 브라우저 데이터나 사이트 데이터를 삭제하면 프로그램 안의 녹음도 삭제될 수 있으므로, 중요한 녹음은 **파일 저장** 버튼으로 별도 보관하세요.

- 현재 음과 목표 음, cents 오차 표시

## 기존 기능

### 메트로놈
- BPM 30~240
- 2/4, 3/4, 4/4, 6/8 박자
- 첫 박자 강조, 볼륨, TAP 템포

### 악기 튜너
- 크로매틱, 기타, 우쿨렐레 튜닝
- 음 이름, 옥타브, 주파수, cents 표시
- 자동 줄 감지와 줄 고정
- A4 기준음 430~450Hz

## 실행 파일이 작동하지 않을 때

훈뮤직툴 폴더의 주소 표시줄에 `cmd`를 입력한 뒤 다음 명령을 실행합니다.

```bash
py -m http.server 8080
```

`py`가 작동하지 않으면:

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.
