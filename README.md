# 훈뮤직툴 v1.8 PC Studio / Mobile App UI

이번 버전은 기능 추가보다 **작업 공간 구조 개편**에 집중했습니다. 같은 기능을 PC와 스마트폰에서 똑같이 축소해서 보여주지 않고, 화면 크기에 따라 서로 다른 작업 흐름을 제공합니다.

## PC·노트북 UI

- 왼쪽 고정 사이드바 메뉴
- 오른쪽 전체 영역을 사용하는 작업실형 화면
- 코드 진행: 설정과 결과·건반을 2열로 동시 표시
- 녹음: MR·싱크 설정과 녹음 목록을 좌우로 분리
- 보컬튠: 연습 설정과 실시간 음정 분석을 동시 표시
- 메트로놈·튜너: 넓은 화면에 맞춘 정보 배치
- 페이지 전체가 아닌 작업 영역만 스크롤되는 데스크톱 앱형 구조

## 스마트폰 UI

- 하단 고정 앱 메뉴
- 한 화면에 한 가지 작업을 집중해서 표시
- 터치 영역과 안전 영역 최적화
- 기존 PWA 설치, MR 녹음, 싱크 보정, 보컬·MR 분리 트랙 기능 유지

## 기준 해상도

- PC Studio UI: 화면 너비 900px 이상
- Mobile App UI: 화면 너비 899px 이하

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 모바일에서는 HTTPS로 배포한 주소를 열어 홈 화면에 설치합니다.
