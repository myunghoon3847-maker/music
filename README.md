# 훈뮤직툴 v1.9.4.1 트랙 추가 오류·UI 수정

PC·모바일에서 사용하는 개인용 음악 작업 웹앱입니다.

## v1.9.4.1 핵심 변경

- 빈 트랙이 추가되지 않던 동작을 수정
- 트랙 추가 시 전체 녹음을 다시 불러오지 않고 타임라인에 즉시 반영
- 재생 영역 아래에 작은 `+` 트랙 추가 버튼 배치
- 길게 펼쳐지던 트랙 추가·녹음 패널 제거
- 녹음·저장·설정 버튼을 한 줄의 간결한 도구 모음으로 정리
- 시작 위치와 카운트인은 `설정`을 눌렀을 때만 표시
- 새 트랙은 `트랙 1`, `트랙 2`처럼 자동 이름 생성
- CSS와 JavaScript에 버전 주소를 적용해 이전 파일이 섞여 보이는 캐시 문제 방지

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 브라우저가 열리지 않으면 폴더 안의 `index.html`을 Chrome 또는 Edge에서 여세요. 마이크와 PWA 기능은 로컬 서버 또는 HTTPS 배포 환경에서 가장 안정적입니다.

## 배포

GitHub Pages나 Netlify에는 배포용 폴더의 파일과 폴더를 그대로 업로드합니다. 이전 버전 위에 덮어쓴 뒤 앱을 완전히 종료하고 다시 열어 서비스 워커 캐시를 갱신하세요.

## 추가 트랙 녹음 방법

1. 믹서에서 보컬과 MR이 분리된 녹음을 선택합니다.
2. 재생 바 아래의 작은 `+` 버튼을 눌러 빈 트랙을 추가합니다.
3. 추가된 트랙이 자동으로 녹음 대상으로 선택됩니다.
4. 타임라인에서 원하는 시작 위치로 재생선을 옮깁니다.
5. 세밀한 시작 시간이나 카운트인이 필요하면 `설정`을 엽니다.
6. `녹음`을 누르고, 끝나면 `저장`을 누릅니다.
7. 파형을 이동·분할·자른 뒤 WAV 믹스를 만들 수 있습니다.

추가 트랙을 녹음할 때는 기존 믹스가 마이크에 다시 들어가지 않도록 유선 이어폰 사용을 권장합니다.
