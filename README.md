# 훈뮤직툴 v1.9.2 파형 타임라인 편집기

PC·모바일에서 사용하는 개인용 음악 작업 웹앱입니다.

## v1.9.2 핵심 변경

- MR·보컬·추가 녹음 트랙의 실제 파형 표시
- 파형 클립을 좌우로 끌어 트랙 싱크 조정
- 클립 양쪽 손잡이와 숫자 입력으로 앞뒤 비파괴 자르기
- 10ms·50ms·100ms 스냅과 타임라인 확대
- 편집 실행 취소·다시 실행 및 Ctrl+Z / Ctrl+Y
- 자르기·이동·페이드 결과를 앱 재생과 WAV 내보내기에 동일하게 반영
- 프로젝트 전환 시 이전 디코딩 데이터와 파형 캐시 정리
- 추가 트랙 녹음 후 새 트랙 자동 선택
- 앱이 백그라운드로 이동하면 녹음을 안전하게 종료

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 브라우저가 열리지 않으면 폴더 안의 `index.html`을 Chrome 또는 Edge에서 여세요. 마이크와 PWA 기능은 로컬 서버 또는 HTTPS 배포 환경에서 가장 안정적입니다.

## 배포

GitHub Pages나 Netlify에는 이 폴더의 파일과 폴더를 그대로 업로드합니다. 이전 버전 위에 덮어쓴 뒤 앱을 완전히 종료하고 다시 열어 서비스 워커 캐시를 갱신하세요.

## 편집 방법

1. 녹음 탭에서 보컬과 MR이 분리된 녹음을 준비합니다.
2. 믹서 탭에서 녹음을 선택합니다.
3. 파형 클립을 좌우로 끌어 싱크를 맞춥니다.
4. 클립 양끝 손잡이 또는 `앞 자르기·뒤 자르기` 숫자로 무음 구간을 정리합니다.
5. 음량·팬·페이드 조절 후 WAV 믹스를 만듭니다.

원본 트랙 파일은 자르지 않습니다. 편집값만 저장하는 비파괴 방식입니다.
