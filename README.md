# 훈뮤직툴 v1.6.4 모바일 · 녹음 플레이어/UI 개선판

저장된 녹음의 플레이 바가 후반부에서 비정상적으로 움직이던 문제와 싱크 조절 UI를 개선한 버전입니다.

## 핵심 변경

- 브라우저 기본 오디오 플레이어를 전용 녹음 플레이어로 교체
- 녹음 당시 측정한 실제 인코딩 시간을 기준으로 플레이 바 표시
- 현재 시간 / 전체 시간 표시
- 재생·일시정지, 재생 위치 이동 지원
- WebM 재생시간을 `Infinity`로 읽는 모바일 브라우저에 대한 보정 처리
- MediaRecorder 조각 생성 주기를 250ms에서 1초로 완화
- 싱크 범위를 `-800ms ~ +800ms`로 확대
- 싱크 슬라이더 중앙을 정확히 `0ms`로 변경
- 싱크 값 직접 입력 및 ±10ms 미세 조절
- 기존에 저장한 싱크 값(예: +390ms)은 그대로 유지
- 음량과 세부 녹음 옵션을 접이식 메뉴로 정리

## 싱크 맞추기

1. 유선 이어폰을 연결합니다.
2. 10~20초 정도 짧게 시험 녹음합니다.
3. 보컬이 MR보다 늦으면 `+10`, 빠르면 `-10`을 누릅니다.
4. 정확한 값을 알고 있다면 숫자 칸에 직접 입력합니다.
5. 설정값은 브라우저에 자동 저장됩니다.

`+390ms`처럼 큰 값이 필요한 경우에도 정상적으로 입력할 수 있습니다. 기기·브라우저·마이크 경로에 따라 필요한 보정값은 달라질 수 있습니다.
