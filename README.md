# 훈뮤직툴 v1.9 2트랙 믹서

보컬과 MR을 분리 저장한 녹음을 파일로 내려받지 않고 앱 안에서 각각 또는 동시에 재생하고, 기본적인 믹싱 설정을 적용할 수 있는 버전입니다.

## 핵심 변경 사항

- 새 `믹서` 탭 추가
- 현재 프로젝트의 저장된 녹음 선택
- MR 트랙만 재생
- 보컬 트랙만 재생
- 보컬과 MR 동시 재생
- 두 트랙을 같은 AudioContext 시간축에 예약해 싱크 유지
- 공통 재생·일시정지·정지와 재생 위치 이동
- 트랙별 음량, 음소거, 솔로, 좌우 팬
- 트랙별 위치를 -1000ms~+1000ms 범위에서 조절
- 트랙별 페이드인·페이드아웃
- 마스터 음량
- 녹음별 믹서 설정 자동 저장
- 녹음 목록의 `믹서로 열기` 버튼
- 기존 합쳐진 녹음은 그대로 재생 가능하며, v1.7 이후 분리 트랙 녹음만 2트랙 믹서 사용 가능

## 믹서 사용

1. 녹음 탭에서 MR과 보컬을 분리 트랙으로 녹음합니다.
2. 저장된 녹음의 `믹서로 열기`를 누르거나 믹서 탭에서 녹음을 선택합니다.
3. `전체 재생`, `MR만 듣기`, `보컬만 듣기`로 트랙을 확인합니다.
4. 음량·팬·트랙 위치를 조절합니다.
5. 설정은 녹음별로 브라우저 저장소에 자동 저장됩니다.

이번 버전은 실시간 미리 듣기와 믹서 설정 저장까지 지원합니다. 조절된 결과를 새 오디오 파일로 생성하는 기능은 다음 단계에서 추가합니다.

## 실행

PC에서는 `훈뮤직툴 실행.bat`을 실행합니다. 모바일에서는 HTTPS 배포 주소로 열어 홈 화면에 설치합니다.
