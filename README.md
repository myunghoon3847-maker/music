# 훈뮤직툴 v1.6.2 모바일

MR 재생·보컬 동시 녹음 안정화판입니다.

## 수정 내용

- MR과 보컬에 걸리던 강한 공동 압축을 분리
- 보컬만 가볍게 정리하고 MR은 원래 다이내믹을 유지
- 최종 피크만 막는 소프트 리미터 적용
- 녹음 전 MR 파일 준비 상태 확인
- 모바일 MR 버퍼링과 시작 시 끊김 완화
- 블루투스 마이크 사용 가능성이 감지되면 음질 저하 안내
- PWA 캐시 버전 갱신

## 권장 설정

- 유선 이어폰 또는 휴대폰 마이크 + 유선 이어폰
- 듣는 MR: 70~90%
- 녹음 속 MR: 55~75%
- 녹음 속 보컬: 80~110%

블루투스 이어폰은 마이크가 활성화될 때 일부 기기에서 통화용 오디오 방식으로 전환되어 MR 음질이 낮아질 수 있습니다.
