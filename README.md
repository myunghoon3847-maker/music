# 훈뮤직툴 v1.6

코드 진행 생성기, 메트로놈, 악기 튜너, 보컬 음정 연습과 함께 **MR 반주를 앱 안에서 재생하고 보컬과 합쳐 녹음하는 기능**을 제공하는 개인용 음악 제작·연습 프로그램입니다.

## 가장 쉬운 실행 방법

1. 압축을 풉니다.
2. 폴더 안의 **`훈뮤직툴 실행.bat`**을 더블클릭합니다.
3. 약 2초 후 Chrome 또는 Edge에서 훈뮤직툴이 자동으로 열립니다.
4. 상단의 **보컬튠** 탭을 누릅니다.
5. **MR 파일 선택**에서 기기에 저장된 MP3·WAV·M4A 등의 반주 파일을 불러옵니다.
6. 이어폰을 연결하고 MR과 보컬의 녹음 음량을 조절합니다.
7. 녹음 이름을 입력한 뒤 **녹음 시작**을 누르고 마이크 권한을 허용합니다.
8. MR이 처음부터 자동 재생되며 보컬과 함께 녹음됩니다.
9. **정지·저장**을 누르거나 MR이 끝나면 녹음 파일이 자동 저장됩니다.

> 보컬튠, 튜너, 녹음 기능은 마이크 보안 정책 때문에 `index.html`을 직접 여는 방식이 아니라 실행 배치 파일 또는 HTTPS 주소로 열어야 합니다.

## v1.6 MR 반주 합성 녹음

- 기기에 저장된 MR 오디오 파일 불러오기
- 프로그램 내부 MR 재생·일시정지·탐색
- MR 처음부터 다시 재생
- 녹음 시작과 동시에 MR 처음부터 자동 재생
- 마이크 보컬과 MR을 Web Audio 방식으로 내부 합성
- 저장 파일에 MR과 보컬을 함께 포함
- 듣는 MR 음량과 녹음 속 MR 음량을 따로 조절
- 녹음 속 보컬 음량 조절
- MR을 들으면서 보컬만 저장하는 선택 가능
- MR 종료 시 녹음 자동 정지·저장
- 녹음 일시정지 시 MR도 함께 정지하고, 재개 시 이어서 재생
- 녹음 목록에 MR 포함 여부 표시
- 녹음 결과 앱 내부 재생·파일 저장·삭제

MR 파일 자체는 서버에 업로드되지 않으며 현재 실행 중인 브라우저 안에서만 사용됩니다. 프로그램을 새로 열면 MR은 다시 선택해야 합니다.

### 이어폰 사용 권장

스피커로 MR을 재생하면 마이크가 스피커 소리도 다시 받아 내부 합성된 MR과 겹치면서 울림이나 이중 반주가 생길 수 있습니다. **유선 또는 블루투스 이어폰을 연결한 상태에서 녹음하는 것이 좋습니다.** 블루투스 이어폰은 기기에 따라 녹음 지연이나 음질 저하가 생길 수 있어 가능하면 유선 이어폰을 권장합니다.

## 녹음 저장

- 실시간 녹음 시간과 마이크 입력 레벨
- 일시정지·계속 녹음
- 정지와 동시에 브라우저 내부 저장소에 자동 저장
- 프로그램 안에서 녹음 재생
- 개별 파일 저장, 개별 삭제, 전체 삭제
- 녹음 이름, 날짜, 길이, 파일 크기 표시
- 새로고침하거나 프로그램을 다시 열어도 녹음 목록 유지
- 최대 30분 자동 제한

녹음 파일은 브라우저의 **IndexedDB 기기 저장 공간**에만 저장됩니다. 브라우저 데이터나 사이트 데이터를 삭제하면 프로그램 안의 녹음도 삭제될 수 있으므로 중요한 녹음은 **파일 저장** 버튼으로 별도 보관하세요.

## 기존 기능

### 보컬튠
- 실시간 보컬 음정 감지
- 현재 음과 목표 음, cents 오차 표시
- 키·스케일·목표음 방식·감지 범위 설정
- 평균 정확도, 유지 시간, 안정도와 음정 그래프

### 코드 생성기
- 메이저·마이너, 장르·분위기별 4코드·8코드 생성
- 확장 코드, 코드 구성음과 피아노 건반 표시
- 개별 코드 교체·재생, 전체 반복 재생, 저장

### 메트로놈
- BPM 30~240, 2/4·3/4·4/4·6/8
- 첫 박자 강조, 볼륨, TAP 템포

### 악기 튜너
- 크로매틱, 기타, 우쿨렐레 튜닝
- 음 이름, 옥타브, 주파수, cents 표시

## 실행 파일이 작동하지 않을 때

훈뮤직툴 폴더의 주소 표시줄에 `cmd`를 입력한 뒤 다음 명령을 실행합니다.

```bash
py -m http.server 8080
```

`py`가 작동하지 않으면:

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.
