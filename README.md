# 훈뮤직툴 v1.6.3 모바일 · 싱크 안정화판

MR과 보컬을 함께 녹음할 때 발생하던 시작 시점 차이와 기기별 입력 지연을 줄인 버전입니다.

## 핵심 변경

- MR을 녹음 전에 `AudioBuffer`로 완전히 불러옴
- MR 재생과 녹음 믹서를 하나의 `AudioContext` 시간축에서 예약
- 3초 카운트인
- 녹음용 MR과 보컬 경로를 분리
- 녹음 싱크 보정: -300ms ~ +500ms, 10ms 단위
- 양수값은 녹음되는 MR을 늦추고, 음수값은 녹음되는 보컬을 늦춤
- 싱크 보정값 기기 저장
- 일시정지·재개 시 MR 위치 복원
- MR 종료 후 지연 신호의 끝부분까지 담고 자동 저장
- 중복 녹음 시작 방지

## 권장 테스트

1. 유선 이어폰을 연결합니다.
2. 보컬튠 → MR 보컬 녹음에서 MR을 선택합니다.
3. 기본값 `+120ms`로 10~20초 녹음합니다.
4. 보컬이 늦으면 `+10ms`, 빠르면 `-10ms`씩 조절합니다.
5. 맞는 값은 브라우저에 자동 저장됩니다.

블루투스 이어폰 마이크는 녹음 시작 시 통화용 오디오 모드로 전환되거나 지연이 크게 바뀔 수 있어 싱크 작업에는 권장하지 않습니다.
